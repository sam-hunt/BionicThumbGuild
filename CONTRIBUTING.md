# Contributing

Thanks for your interest in improving Bionic Thumb Guild! Bug reports,
suggestions and pull requests are welcome.

## Localization

| Language | Status | Credit |
| -------- | ------ | ------ |
| English  | Source | —      |

No translation files exist yet — English lives only in the Defs/ XML (labels,
descriptions, interaction log rules), and there is no `Languages/` folder yet
for any language, including English. Translations for any language RimWorld
supports are welcome. See "Contributing a translation" below for the
conventions to follow once that structure is in place.

Statuses: **Source** (the authoritative English strings), **Machine-assisted**
(generated with terminology grounded against the official RimWorld
localization; awaiting native review), **Native** (written or reviewed by a
native speaker), **Planned** (not started — contributions welcome).

### Contributing a translation

- Files live under `1.6/Languages/<Language>/` (`Keyed/` and `DefInjected/`),
  mirroring the structure of `1.6/Languages/English/`.
- Every translated entry carries the current English source in a comment
  directly above it, e.g. `<!-- EN: 120% manipulation efficiency -->` — this
  is how stale translations are detected when the English changes.
- Placeholders (`{0}`, `{1}`, ...) must match the English exactly.
- This mod's translatable content is DefInjected only, sourced from its
  ThingDefs, HediffDefs, RecipeDefs, ThoughtDefs, and InteractionDefs
  (labels, descriptions, and interaction log rules) — there are no Keyed
  strings in code yet.
- Formatting: UTF-8 without BOM, LF line endings, 2-space indent.
- Validate before opening a PR:

  ```bash
  python3 Scripts/check-translations.py --strict
  ```

  It checks key coverage, placeholders, DefInjected paths, staleness, and
  file hygiene. The checker's engine lives in the `l10n/` git submodule, so
  clone with `git clone --recurse-submodules` (or run
  `git submodule update --init` in an existing clone) before validating. It
  relies on `Scripts/expected-injections.json`, a sidecar generated by a
  supervised game run (`Scripts/refresh-translation-expectations.py`); if it
  is missing or stale, ask a maintainer to regenerate it before your PR can
  be validated.

- Improving a machine-assisted language? Corrections from native speakers
  are gladly merged, no matter how small.
